About this Site

2026/03/22

This site is built with Hugo using the XMin theme designed by Yihui Xie — an extremely minimal theme, about 140 lines of HTML and CSS in total, built with the philosophy of keeping things simple without sacrificing readability.

The theme’s clean design and zero-JavaScript approach made it the perfect foundation for this site.

If you’re looking to build your own Hugo site, XMin is a great place to start.
